Road requirement (JSON)

Paste a road-illuminate requirement set as is, or wrap it as "checks" with vehicle settings. Check types: point, range, width, zone, with op and limit; y is positive to the left, as in road-illuminate. Optional z per check sets its evaluation height. Optional class (B, CS, DS, ES; driving beam BS, DSES). Optional targets: imax, flux_lm, spreadH_deg, spreadV_deg. Optional roadFlux: target_lm, lamps (one or pair), zone {x1, x2, left, right}.

Vehicle

Flux on road

Luminous flux reaching the road surface inside this rectangle, measured from the lamps. Default target: 600 lm (Class B, DS, ES and high beam), 300 lm (Class CS).

Cut-off geometry (low beam)

Elbow on the V-V line. Gradient width sets cut-off sharpness (logistic scale). Symmetric classes use a flat cut-off, so shoulder angle and top are fixed.

Regulation test table

Entries: point (h, v), zone polygon, sum of point ids, or imax. Limits: min, max, minRatioImax, maxRef {id,k}. Always written for RHT; LHT is mirrored.
