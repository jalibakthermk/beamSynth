Beam parameters

Q shapes the bottom of the beam, from a “+” shape at 0 to a strong smile at 1. Q does not move the hot spot or change the H spread. Default hot spot: 75R (75L in LHT) for Class B, 0.86D on V-V for symmetric classes, H-V for the high beam.

Road requirement (JSON)

Paste a road-illuminate requirement set as is, or wrap it as "checks" with vehicle settings. Check types: point, range, width, zone, with op and limit; y is positive to the left, as in road-illuminate. Optional z per check sets its evaluation height. Optional class (B, CS, DS, ES; driving beam BS, DSES). Optional targets: imax, flux_lm, spreadH_deg, spreadV_deg. Optional roadFlux: target_lm, lamps (one or pair), zone {x1, x2, left, right}.

Vehicle

Physical limits

With an aperture given, Imax is held at or below LED luminance × aperture area, the most any optic can deliver. Efficiency converts the emitted flux into the LED flux needed. Leave the aperture blank for no limit.

Aim tolerance

At 0 the beam is solved for nominal aim only. Set a tolerance and the beam must pass ECE with the lamp mis-aimed anywhere in that box. A Class B beam can pass up to ±0.4° H with ±0.2° V; beyond that the cut-off shoulder reaches the 75R point.

Flux on road

Luminous flux reaching the road surface inside this rectangle, measured from the lamps. Leave the minimum blank to get the least flux that meets the requirements; set it only when a minimum flux on road is required.

Cut-off geometry (low beam)

Elbow on the V-V line. G is the cut-off sharpness as R149 measures it: G = log E(β) − log E(β + 0.1°) on a vertical scan at 2.5°. The tool calibrates the cut-off so its steepest point sits on the elbow line. Symmetric classes use a flat cut-off, so shoulder angle and top are fixed.

Regulation test table

Entries: point (h, v), zone polygon, sum of point ids, or imax. Limits: min, max, minRatioImax, maxRef {id,k}. Always written for RHT; LHT is mirrored.
